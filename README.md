# Gerador de Assinatura - HTML simples

Este pacote não precisa de Node.js, instalação ou compilação.

## Estrutura

```text
index.html
icones/
orgaos-entidades/
```

## GitHub Pages

1. Crie um repositório no GitHub.
2. Envie `index.html` e as duas pastas para a raiz do repositório.
3. Abra **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Selecione a branch **main**, a pasta **/(root)** e clique em **Save**.
6. Aguarde a publicação e abra o endereço exibido pelo GitHub.

Não altere os nomes ou a localização das pastas sem atualizar os caminhos dentro de `index.html`.
